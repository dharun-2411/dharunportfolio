# Dharun J — Personal Portfolio

A responsive, editorial-style portfolio website with a custom 3D orb interaction, motion, hover effects, and mobile navigation.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Customize
- Edit content in `index.html`.
- Change visual design in `style.css`.
- Change interactions in `script.js`.
- Replace the LinkedIn URL/email/phone if needed.

No framework or build step is required.
